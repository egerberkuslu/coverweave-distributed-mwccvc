# Results of the submitted version

Everything under `results/bb/` was measured before the revision, with several
code versions. The rows of `full_v3/` carry four different code fingerprints,
and the `sweep_*_v2` and `sweep_*_v3` directories, `report/` and
`report_full_v3/` come from earlier versions still. These files are kept as the
record behind the submitted manuscript and are not used by the revised one.

The revised manuscript reports only runs of the frozen tag `coverweave-r1-frozen`,
as the pre-registration in `contract/R1_PREREG.md` requires. Those results are
added in their own directory when the pre-registered runs finish, and every row
there carries the single fingerprint of the frozen code.
